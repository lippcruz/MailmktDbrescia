# DBrescia - Mail Marketing e Assinatura de E-mail

Repositório com os templates de marketing para a D'Brescia, incluindo páginas e assinatura de e-mail.

---

## Estrutura do projeto

- `assinaturaEmail/index.html` — modelo de assinatura de e-mail
- `b2b/index.html` — página de e-mail marketing corporativo (B2B)
- `b2c/index.html` — página de e-mail marketing para clientes finais (B2C)

---

## Como visualizar

Abra os arquivos em seu navegador ou use o pré-visualizador do editor para conferir o resultado.

---

## Uso

- Edite os arquivos HTML diretamente para ajustar o conteúdo, imagens, links e estilo.
- Mantenha as imagens e URLs atualizados de acordo com a produção.
